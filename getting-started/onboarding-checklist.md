- [ ] [Glossary of Program Terms](glossary.md) — get familiar with program-specific terminology
- [ ] [CX Guidelines](/cx-guidelines) — design/UX standards, accessibility, and localization requirements
- [ ] [NPI Operations](/npi-operations) — readiness checklists and content delivery SLAs for launch
- [ ] [Theme Release](/theme-release) — release notes for the version you're implementing
- [ ] [Support](/support) — how to file tickets, request content, and reach the APP Digital Program team

## Account & technical setup

- [ ] [Access & Account Provisioning](access-provisioning.md) — request access and confirm your role/permissions
- [ ] [Integration Setup](integration-setup.md) — choose your integration path (Shopify API vs. Flat File)
- [ ] [First Project Walkthrough](first-project-walkthrough.md) — complete your first guided project

## Owners

| Task | Owner |
|---|---|
| Documentation review | Partner |
| Access provisioning | APP Digital Program team |
| Integration path setup | Partner + APP Digital Program team |
| First project walkthrough | Partner |

## Exit criteria

- [ ] All documentation above has been reviewed
- [ ] Partner has access to all required systems
- [ ] Integration path is chosen and configured
- [ ] First project walkthrough is complete

{% hint style="success" %}
Once every item above is checked, you're ready to move into the next phase of the program.
{% endhint %}
