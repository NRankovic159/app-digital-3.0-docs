# Glossary of Program-Specific Terms

{% hint style="info" %}
**Applies to:** Shopify / CX-S / Both — _(update per-topic if a page is Shopify-only or CX-S-only)_
{% endhint %}

## A–F

* **APP (Apple Premium Partner)** — A retail partner authorized to sell Apple products through a premium, Apple-aligned shopping experience.
* **APP Digital Program** — The program that governs and supports APPs' digital storefronts, from onboarding through ongoing operations.
* **BOPIS** — Buy Online, Pick Up In-Store.
* **Change Log** — The version history maintained for each Features & Functionality article, tracking what changed between releases.

{% hint style="warning" %}
**CX-S** — _(draft definition — confirm with the program team)_ shorthand for partners running a custom-built storefront experience, as distinct from partners integrated via the Shopify platform.
{% endhint %}

* **Flat File** — A batch data delivery method where catalog/product data is submitted as a structured file (e.g. CSV) on a schedule, rather than through a live API.

## G–M

* **Go-Live** — The date a partner's storefront becomes publicly available to customers.
* **Milestone** — A defined checkpoint in the APP Digital Program project plan (e.g. Due Diligence sign-off, Implementation complete).

## N–S

* **NPI** — New Product Introduction; the process and operational readiness work tied to announcing and launching new products.
* **RTL** — Right-to-left; describes the text/layout direction required for certain locales (e.g. Arabic, Hebrew).
* **SLA** — Service Level Agreement; the committed response or delivery time for a given process (e.g. content delivery, support tickets).
* **SMB / B2B** — Small and Medium Business / Business-to-Business; a storefront experience tailored to business buyers rather than individual consumers.

## T–Z

* **Theme** — The underlying storefront codebase/template (e.g. "Theme 3.0") that defines a partner's site structure and features.
* **UAT** — User Acceptance Testing; the phase where partners validate functionality before go-live.
* **Universal Platform** — The unified Shopify-based platform APPs migrate to as part of the APP Digital Program.
