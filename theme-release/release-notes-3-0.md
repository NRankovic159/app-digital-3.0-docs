# 3.0 Theme Release Notes

## Overview

**About v3.0**

Version 3.0 is a merchandising-and-conversion release. It introduces the Frequently bought together module — a multi-item "add all" block on the product page — together with automatic gift-with-purchase, energy-rating labels on product cards, and per-product order limits for controlling how many of an item a shopper can buy. A new Motif homepage preset ships alongside them to show off the content-section library in a ready-made layout.

The rest of the release is refinement: the cart now self-heals grouped add-on rows on load, frequently-bought-together cards can show a monthly-price line, recommendation de-duplication is tighter, and there is a round of performance and stability maintenance across the cart and product pages.
